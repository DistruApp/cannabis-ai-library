# Gate 4 triage, 2026-11-11

Source run: `plugin-evals/results/release-gate4/needs-bash.json` (41 `needs-bash` cases, sonnet agent, sonnet judge, 3 runs). 13 of 41 met the pass mark. This file classifies every failed grader in the 28 cases below their mark, from the grader definition and the agent's final reply (`evidence`).

Classes:
- **SKILL DEFECT**: the reply breaks the skill's own contract or the eval's intent. Fixed in SKILL.md (or its description).
- **GRADER WRONG**: the grader asks for something the skill doesn't promise, or a regex is too literal for a correct answer. Fixed in `build_suite.py` or the eval, and the fix still fails a wrong answer.
- **JUDGE ERROR**: API error, or votes that contradict the evidence. Re-run with `--judge-model opus`.

Caveat: the compliance `state-profiles.md` copies and some descriptions changed mid-run, so compliance results from this run are stale. They are triaged anyway and all are re-run.
