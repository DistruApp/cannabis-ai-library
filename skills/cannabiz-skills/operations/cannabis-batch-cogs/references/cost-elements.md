# Cost elements in cannabis manufacturing batches

What belongs in each bucket, and the questions to ask when a value is missing. No market prices here on purpose: always use the operator's own costs.

| Bucket | Typical components | Ask the operator |
|---|---|---|
| Cannabis inputs | Flower, trim, fresh-frozen or dried biomass, crude, distillate, rosin/resin, kief, infused intermediates | Purchase cost or internal transfer cost? Which lot/harvest? Price unit ($/g, $/lb, $/kg)? |
| Non-cannabis ingredients | Terpenes, carrier oils, edible base ingredients, flavorings | Price unit; actual vs. recipe quantity |
| Hardware | Cartridges, batteries, pods, pre-roll cones/tubes | Defect/reject rate this batch? Overage ordered? |
| Packaging & labeling | Retail box, jar, child-resistant packaging, labels, inserts, shrink | Were extra labels printed and scrapped? |
| Processing consumables | Solvents, ethanol, filtration media, CO2, nitrogen | Charged per batch or allocated? |
| Direct labor | Extraction, post-processing, filling, packaging, QC hours | Loaded rate (wages + payroll taxes + benefits)? Hours from timesheets or estimate? |
| Overhead | Facility rent, utilities, equipment depreciation, indirect staff, insurance | Allocation method used in the books: per batch, per labor hour, per machine hour, or % of materials |
| Testing | Required compliance testing, R&D/potency checks, retests after failures | Lab invoice for this batch? Any retest? |

## Questions that usually explain a cost jump

1. Did an input lot cost change (new biomass or distillate lot)?
2. Did output units drop (yield, rejects, sample pulls)?
3. Was there a retest or remediation?
4. Did the batch size change (fixed testing and setup costs spread over fewer units)?
5. Did the overhead rate or method change between periods?
