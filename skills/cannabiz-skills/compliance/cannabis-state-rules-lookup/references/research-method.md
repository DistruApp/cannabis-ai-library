# Live research method

Use this only when the state profile doesn't cover the question or might be out of date.

## Source priority (stop at the first one that answers it)

1. **The state regulator's own site.** Rules page, guidance documents, FAQs, industry advisories. Regulator URLs are listed in `state-profiles.md`.
2. **The official administrative code or register.** The state's code publisher, secretary of state, or legislature site.
3. **Official traceability guidance.** For Metrc states, that state's Metrc bulletins (archive at https://www.metrc.com/information-and-materials/bulletin-archive, filtered by state code) and the state partner page `https://www.metrc.com/partner/{state}/`. A bulletin explains *how*; the regulation sets *what's required*. Cite both when they differ.
4. **Secondary sources** (law-firm alerts, Cornell LII, trade press). These are only for *finding* the primary source. Cite one only if the primary source can't be reached, and label it "secondary source".

Never cite: AI-generated summaries, vendor marketing copy (except to say which vendor a state uses, labeled "Vendor-only"), or forum posts.

## What to record for every rule

| Field | Example |
|---|---|
| Citation | 4 CCR §15051 |
| URL | https://www.cannabis.ca.gov/cannabis-laws/dcc-regulations/text-of-regulations/ |
| Exact operative text | "…at least once every 30 calendar days…" |
| Effective date / version | Compilation in effect as of 2026-10-01 |
| Accessed date | 2026-10-16 |
| Official vs. unofficial | Unofficial compilation; official text is in the CCR |
| Pending changes found | DCC-2026-02-R (text not reviewed) |

## If a site blocks access

Several state sites block automated access (as of 2026-10-16: michigan.gov, azdhs.gov, commerce.alaska.gov, com.ohio.gov). Don't fill the gap from memory. Tell the user which page to open, what to look for, and give the answer as **UNVERIFIED** until they confirm it.
