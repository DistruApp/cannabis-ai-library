# Compliance

State rules, inspections, traceability, transfers and SOPs.

- **[cannabis-state-rules-lookup](./cannabis-state-rules-lookup/SKILL.md)**: Answer state cannabis rule questions with a cited, dated answer from primary sources. Flags anything it can't verify instead of guessing.
- **[cannabis-inspection-readiness](./cannabis-inspection-readiness/SKILL.md)**: Prepare for a state inspection or audit with a readiness checklist, binder index, gap list with owners and due dates, and mock inspection questions.
- **[cannabis-traceability-reconciliation](./cannabis-traceability-reconciliation/SKILL.md)**: Compare a Metrc or BioTrack export with a physical count or ERP export and produce a discrepancy report with likely causes. Adjustments are drafts only.
- **[cannabis-transfer-manifest-precheck](./cannabis-transfer-manifest-precheck/SKILL.md)**: Check an outgoing B2B transfer against the sales order and active inventory with lab status. Returns GO or HOLD per line with the fix needed.
- **[cannabis-sop-generator-trainer](./cannabis-sop-generator-trainer/SKILL.md)**: Turn a described process into a licensing-ready SOP, then build a training packet with a quick reference, comprehension check and sign-off log.
